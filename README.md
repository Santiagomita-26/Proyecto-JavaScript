# 🚌 Rutas Seguras Kids

## 📌 Descripción del proyecto

Rutas Seguras Kids es una aplicación frontend desarrollada con HTML, CSS y JavaScript Vanilla que permite administrar rutas escolares y estudiantes de manera dinámica.

El sistema permite crear rutas, asignar estudiantes, editar información y eliminar registros, todo desde una interfaz moderna y responsiva. Además, incorpora consumo de APIs externas para mostrar información climática en tiempo real.

El proyecto fue desarrollado sin frameworks ni librerías externas, con el objetivo de fortalecer habilidades en manipulación del DOM, asincronía, Web Components y organización de proyectos frontend.

# 🚀 Instrucciones de ejecución

## 1. Clonar el repositorio

```bash
git clone https://github.com/Santiagomita-26/Proyecto-JavaScript.git
```

---

## 2. Entrar a la carpeta del proyecto

```bash
cd Proyecto-JavaScript
```

---

## 3. Abrir el proyecto

Abrir el archivo:

```bash
index.html
```

en cualquier navegador moderno.

También puedes utilizar la extensión **Live Server** de Visual Studio Code para ejecutar el proyecto de manera local.
